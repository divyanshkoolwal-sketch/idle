# Idle

**Idle is a real-time spot market where AI agents bid for GPU time from data centers.**
Every job is auctioned in milliseconds. Agents pay per job in AUSD over x402 and per token over XRPL Payment Channels.
Data centers are verified with XRPL Credentials, which are revoked automatically when a data center cheats.

Built at B@BHacks 2.0. See `IDLE_BUILD_PLAN.md` for the full design.
